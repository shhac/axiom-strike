# Audio credits

Every file in this folder is derived from a source released under
**CC0 1.0 Universal (public domain dedication)**, confirmed on the source page
(and in the pack's own licence/info file where one ships). No attribution is
legally required; it is listed here as a courtesy and as a provenance record.

All files were converted to MP3 (96 kbps, 44.1 kHz), level-adjusted, and (for
effects and jingles) trimmed of leading/trailing silence. Music and
`jingle_victory` / `jingle_defeat` are stereo; everything else is mono.
